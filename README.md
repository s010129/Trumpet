# 口袋小號

用手機或 iPad 吹奏的小號網頁 App。單一 `index.html`，不需要安裝任何東西。

## 功能

- **三個活塞可以自由擺位**：按「位置」後拖曳 1、2、3 號活塞和音域條；音域條拉角落的圓點可以改大小，也能拉成橫的。直拿、橫拿各記一組位置，另外可以調整按鍵大小。
- **聲道輸出**：設定裡可選「左右聲道」、「只有左」、「只有右」，並有「試聽」按鈕確認。單聲道模式會把聲音合併到選定那一邊。
- **兩種吹奏方式**
  - 觸控發聲：左手按住音域條就發聲，放開就停（像吐音），手指在音域條上滑動可以換音域。
  - 麥克風吹氣：對著麥克風吹氣發聲，吹越用力越大聲、越亮；可調靈敏度並看即時音量條。
- **真實指法**：B♭ 小號（也可切換 C 小號），音域 F♯3–C6，和真的小號指法相同。內建指法表，點一下可試聽。
- 音名可顯示 C D E 或 Do Re Mi；可調音量、殘響、抖音。
- 可加到主畫面全螢幕使用，離線也能開（Service Worker）。

## 操作

| 動作 | 觸控 | 電腦鍵盤 |
| --- | --- | --- |
| 發聲 | 按住音域條（或麥克風模式吹氣） | 空白鍵，或 1–6 直接選音域並發聲 |
| 換音域（泛音） | 音域條上下滑 | 1–6、↑ ↓ |
| 活塞 1 / 2 / 3 | 點按活塞 | J / K / L |

畫面上顯示的是小號記譜音；B♭ 小號實際發出的音比記譜低一個全音，標題列下方會同時顯示實際音高與頻率。

## 放到網路上（GitHub Pages）

1. 在 GitHub 的這個 repo 進入 **Settings → Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 約一分鐘後會出現網址（例如 `https://<帳號>.github.io/<repo>/`），用手機 Safari / Chrome 打開即可。
4. iPhone / iPad：分享 → **加入主畫面**，就能像 App 一樣全螢幕開啟。

麥克風吹氣需要 https 網址（GitHub Pages 已經是 https），第一次使用時瀏覽器會詢問麥克風權限。

## 小提醒

- iPhone 若沒有聲音，請調高音量並確認沒有開啟靜音模式（iOS 16.4 以上會自動略過靜音開關）。
- 麥克風模式建議戴有線耳機，避免喇叭的聲音被麥克風收進去。iPhone 搭配藍牙耳機時，系統可能改用耳機麥克風並變成單聲道，這時左右聲道設定會失效。
- 設定與按鍵位置存在瀏覽器裡（localStorage），換瀏覽器或清除網站資料後會回到預設。

## 檔案

- `manifest.webmanifest`、`sw.js`、`icons/`：加入主畫面與離線用
